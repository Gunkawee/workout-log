# สมุดบันทึกเวท

เว็บแอปบันทึกน้ำหนัก/จำนวนครั้งทีละเซ็ต ตามตาราง 5 วัน เก็บข้อมูลในเบราว์เซอร์ ฟรี ไม่ต้องติดตั้ง

## เปิดใช้งานในเครื่อง
`python3 -m http.server -d workout-log` แล้วเปิด http://localhost:8000 (หรือดับเบิลคลิก `index.html`)

## ขึ้นเว็บฟรี (GitHub Pages)
1. อัปโหลดโฟลเดอร์ `workout-log` ขึ้น GitHub repo
2. Settings → Pages → เลือก branch และโฟลเดอร์ที่มี `index.html`
3. เปิดลิงก์บนมือถือ แล้ว "เพิ่มลงหน้าจอโฮม"

## สำรองข้อมูล
ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น (ล้างข้อมูลเบราว์เซอร์ = หาย) ไปที่ ตั้งค่า → "ส่งออกข้อมูล" เป็นระยะ และใช้ "นำเข้าข้อมูล" เพื่อกู้คืน

## เทสต์ตรรกะ
`node --test workout-log/tests/logic.test.js`
